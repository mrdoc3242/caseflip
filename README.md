# CaseFlip

Сайт с кейсами, апгрейдами, контрактами, батлами и крашем. RTP всех режимов 97.5%, каждый результат проверяется (provably fair). Сейчас это демо с виртуальным балансом.

## Что внутри

| Путь | Что это |
|---|---|
| `src/engine.js` | Предметы, кейсы, решатель шансов под RTP 97.5%, HMAC-роллы |
| `src/games.js` | Правила всех режимов. Одинаково работают на сервере и в браузере |
| `src/app.html`, `src/app.js`, `src/app_more.js`, `src/i18n.js` | Интерфейс, RU/EN |
| `server/server.js` | Сервер на Node 22 без зависимостей (встроенный SQLite) |
| `dist/` | Готовый сайт: `index.html`, `catalog.json` (13 тыс. скинов с ценами), `sprites/` (картинки) |
| `test.js` | Проверка RTP всех режимов |

Без сервера `dist/index.html` работает как демо прямо в браузере (прогресс хранится в localStorage). С сервером включаются общий аккаунт, Steam, лента дропов всех игроков, чат, общий краш, рефералы, промокоды и вывод.

## Запуск у себя

```bash
node build.js       # собрать dist/index.html
node test.js        # проверить RTP (в конце "ALL OK")
npm start           # http://localhost:8080
```

Нужен Node.js 22.5 или новее.

## Настройки сервера (переменные окружения)

| Переменная | По умолчанию | Зачем |
|---|---|---|
| `PORT` | 8080 | Порт |
| `DATA_DIR` | `./data` | Где лежит база SQLite и обновлённые цены. На хостинге это должен быть постоянный диск |
| `PUBLIC_URL` | из заголовков | Адрес сайта, например `https://caseflip.onrender.com`. Нужен для возврата из Steam |
| `STEAM_API_KEY` | пусто | Ник и аватар из Steam. Ключ: https://steamcommunity.com/dev/apikey |
| `ADMIN_TOKEN` | пусто | Включает админ-API (промокоды, заявки на вывод, баны) |
| `DEMO_MODE` | 1 | Виртуальные деньги и кнопка «+$500» |
| `START_BALANCE` | 1000 в демо | Стартовый баланс |
| `MAX_BET` | 1000 | Максимальная ставка |
| `WITHDRAW_DAILY_USD` | 200 | Лимит вывода в сутки на игрока |
| `WITHDRAW_PER_DAY` | 3 | Заявок на вывод в сутки |
| `MARKETCSGO_KEY` | пусто | API-ключ Market.CSGO: покупка скинов для вывода |
| `WAXPEER_KEY` | пусто | API-ключ Waxpeer: запасной маркет для вывода и его цены |
| `MARKETS` | `marketcsgo,waxpeer` | Какие маркеты использовать |
| `WITHDRAW_AUTO_USD` | 50 | Заявки до этой суммы выводятся автоматически, дороже ждут подтверждения админа |
| `WITHDRAW_SLIPPAGE` | 0.10 | Насколько можно переплатить, если цена на маркете выросла с последнего обновления |
| `WITHDRAW_ATTEMPTS` | 2 | Сколько маркетов пробовать для одного предмета, потом он возвращается игроку |
| `PRICE_REFRESH_MIN` | 60 | Как часто обновлять цены, в минутах |
| `WAGER_X` | 3 | Во сколько раз нужно проставить бонусы перед выводом |
| `REF_REWARD` / `REF_WAGER` | 5 / 20 | Награда пригласившему, когда друг поставил столько-то |
| `GUESTS_PER_IP_DAY` | 5 | Новых гостевых аккаунтов с одного IP в сутки |
| `CHAT_MIN_LEVEL` | 2 | С какого уровня можно писать в чат |

## Защита от абьюза (уже в коде)

- Ежедневный бонус один раз в 24 часа на аккаунт и один раз на IP.
- Промокод один раз на аккаунт и один раз на IP, с лимитом активаций и сроком.
- Реферальная награда платится, только когда приглашённый поставил `REF_WAGER`, и не платится, если IP совпадает.
- Демо-пополнение только при балансе меньше $10, раз в 30 минут, не больше 10 раз в сутки с IP.
- Вывод: только после входа через Steam, нужна trade-ссылка, бонусы проставлены ×`WAGER_X`, суточный лимит суммы и количества заявок. Заявка уходит в статус `pending`, предметы замораживаются, игрок может отменить.
- Лимит запросов на IP, блокировка параллельных ставок одного игрока, CSRF-заголовок, HttpOnly-cookie, CSP.

## Админ-API

Заголовок `Authorization: Bearer <ADMIN_TOKEN>`, тело JSON, плюс заголовок `X-CF: 1` для POST.

```bash
# создать промокод на $5, 500 активаций, 7 дней
curl -X POST https://ВАШ-САЙТ/api/admin/promo -H "Authorization: Bearer $ADMIN_TOKEN" -H "X-CF: 1" -H "Content-Type: application/json" -d '{"code":"WELCOME5","amount":5,"uses":500,"days":7}'
curl https://ВАШ-САЙТ/api/admin/withdrawals -H "Authorization: Bearer $ADMIN_TOKEN"
curl -X POST https://ВАШ-САЙТ/api/admin/withdrawal -H "Authorization: Bearer $ADMIN_TOKEN" -H "X-CF: 1" -H "Content-Type: application/json" -d '{"id":1,"status":"sent"}'
curl https://ВАШ-САЙТ/api/admin/stats -H "Authorization: Bearer $ADMIN_TOKEN"
```

Также есть `/api/admin/ban` (`{"id":5,"banned":true}`) и `/api/admin/chat/hide` (`{"id":123}`).

## Цены и вывод скинов через маркетплейсы

Своих Steam-ботов не нужно. При выводе сайт покупает скин на P2P-маркетплейсе методом «купить для другого», и продавец отправляет трейд прямо на trade-ссылку игрока.

- **Market.CSGO** (основной): `buy-for` по названию с потолком цены, статус по нашему `custom_id` (`get-list-buy-info-by-custom-id`: stage 2 получено, 5 отменено).
  Валюта аккаунта может быть USD, EUR или RUB: цены на сайте в долларах, а потолок покупки и баланс пересчитываются по курсу из публичных прайсов маркета.
- **Waxpeer** (запасной): `buy-one-p2p-name`, статус `check-many-project-id` (5 получено, 6 отменено).

Цены на сайте берутся с этих же маркетов: для каждого скина минимальная живая цена среди подключённых маркетов, обновление раз в час. Предметы кейсов привязаны к реальным скинам, шансы кейсов пересчитываются после каждого обновления цен, RTP остаётся ровно 97.5%. Если маркеты недоступны, используется Skinport.

Как идёт вывод: заявка → покупка на маркете, где скин дешевле, с потолком «цена сайта +10%» → продавец шлёт трейд (обычно до 15 минут) → сервер раз в 30 секунд проверяет статус. Если продавец не отправил или скина нет, пробуем второй маркет, потом возвращаем предмет в инвентарь. Если на балансе маркетов не хватает денег, заявка ждёт пополнения, предмет остаётся зарезервированным.

Админ-API: `GET /api/admin/markets` (балансы и очередь), `GET /api/admin/purchases`, `POST /api/admin/withdrawal` с `{"id":1,"action":"approve"}` или `"reject"`.

## Деплой

### Вариант А. Render (проще всего, ~$7.25 в месяц)

1. Залейте эту папку в репозиторий на GitHub.
2. На https://render.com нажмите New → Blueprint и выберите репозиторий. `render.yaml` создаст сервис с диском.
3. В настройках сервиса задайте `PUBLIC_URL` (адрес вида `https://caseflip.onrender.com`) и, по желанию, `STEAM_API_KEY`.
4. Бесплатный план Render тоже запустится, но без постоянного диска база будет стираться при каждом перезапуске.

### Вариант Б. Бесплатно: свой сервер + DuckDNS

1. Возьмите бесплатную VM (например, Oracle Cloud Always Free) с Ubuntu, поставьте Docker.
2. Получите бесплатный поддомен на https://www.duckdns.org и направьте его на IP сервера.
3. Скопируйте проект на сервер, создайте `.env` по образцу `.env.example`.
4. `docker compose up -d`. Caddy сам получит HTTPS-сертификат.

## Чего здесь нет и что нужно сделать вам

Это демо. Перед приёмом реальных денег нужно:

1. **Лицензия.** Кейсы и апгрейды на скины с выводом считаются азартными играми в большинстве стран. Нужна игорная лицензия (часто берут Curaçao или Anjouan) и юрист. В России азартные игры онлайн разрешены только через ЦУПИС у лицензированных букмекеров, поэтому такие сайты работают на зарубежное юрлицо и не принимают игроков из РФ официально.
2. **Правила Steam.** Steam Subscriber Agreement запрещает использовать аккаунты и предметы для азартных игр. Valve периодически блокирует trade-ботов таких сайтов. Это риск, который нельзя убрать кодом.
3. **Платежи.** Подключить платёжного провайдера, который работает с игорным бизнесом (high-risk merchant), или крипто-процессинг. Депозит на сервере зачисляет баланс через webhook провайдера.
4. **Вывод.** Уже работает через Market.CSGO и Waxpeer, нужны только API-ключи и пополненный баланс на маркетах.
5. **KYC и AML.** Проверка возраста и личности при выводе, мониторинг подозрительных операций.
6. **Юридические тексты.** Шаблоны соглашения, политики и «ответственной игры» уже на сайте. Их нужно заполнить реквизитами и отдать юристу.
7. **Бренд.** Не используйте логотипы и товарные знаки Valve и Counter-Strike в названии и оформлении.
